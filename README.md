# multimodal-video-summarizer
AI-powered multimodal video summarization and RAG assistant that summarizes videos from URLs or uploaded files.

## Contributing

Contributions are welcome!

If you would like to improve this project, fix a bug, improve the summarization pipeline, add a new feature, or improve the documentation, you are welcome to contribute.

Please read our **[Contributing Guide](CONTRIBUTING.md)** before submitting changes.

### Quick Contribution Workflow

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Test your changes.
6. Push your branch.
7. Open a Pull Request.
